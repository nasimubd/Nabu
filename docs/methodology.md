# Analysis methodology

## Evidence levels

- **Observed**: directly reproduced from source, disassembly, or controlled execution.
- **Corroborated**: supported by at least two independent observations.
- **Inferred**: a reasoned interpretation that needs further validation.
- **Unknown**: not established by the available evidence.

## Case minimums

Each case records the target origin, exact revision, acquisition date, platform, architecture, SHA-256, license, and analysis scope. Do not commit proprietary inputs, credentials, personal data, or generated databases.

## Comparison format

Compare behavior and interfaces using concrete evidence. Record the target behavior, reference behavior, observed difference, confidence, and proposed implementation consequence. Keep speculation separate from findings.
